# Product
<!-- impeccable:product-schema 1 -->

## Platform
macOS native (AppKit).

## Users and purpose
A person tracks the overall checkpoint of explicitly enrolled projects across participating agent sessions from the menu bar. The view is glanceable and does not replace session-level work tracking.

## Constraints
Only explicit enrollment and session association; no discovery or automatic backlog import. Checklist items represent saved milestone state, may contain nested substeps and are display-only; disclosure choices are per project. Token estimates are optional, sourced and scoped, and are never inferred or apportioned. Legacy records have no inferred milestones. No server or model runs for viewing.

## Evidence
A user-selected screenshot establishes the dark rounded menu-bar popover composition. Branding and permanent product name remain undecided. Fictional fixture data is used for visual checks.
