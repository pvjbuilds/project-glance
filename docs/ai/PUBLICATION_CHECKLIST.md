# Before any public release

This is a future checklist, not authorization to publish.

- Obtain the designated independent review under the currently recorded review mode for a frozen revision; resolve findings and validate applicable native acceptance criteria. Same-provider review retains shared blind spots.
- Reconcile the architecture source and have the designated reviewer render and validate the diagram using the available tooling.
- Decide a public name and license; audit source, history, bundled artifacts and examples for personal paths, private information and secrets before the first commit and again before any publication.
- Prepare a tested installation and update path, accessibility and macOS compatibility information, and a release process. Verify login-item behavior only with explicit user action.
- Complete the public repository discoverability requirements in RULES §11: description, topics, current diagram, FAQ questions, install-with-agent prompt, AGENTS.md, release pages and social preview; verify remote state separately.
